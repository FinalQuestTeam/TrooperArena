sprite_eng.h Motor de sprites (Sprite Engine)

Motor de sprites do SGDK, oferecendo manipulação avançada de sprites (meta-sprites) sobre o hardware do Mega Drive/Genesis. Um "sprite" do motor é uma entidade de alto nível composta por um ou mais sprites de hardware do VDP (cada um de até 4×4 tiles), com animações, frames, ordenação por profundidade (depth/Z), flip horizontal/vertical, alocação automática de VRAM e upload automático de tiles via DMA. Este módulo usa o gerenciador de memória de VRAM (vram.h) e as capacidades de sprite do VDP (vdp_spr.h). Use-o sempre que precisar exibir personagens, inimigos, projéteis e demais objetos animados: inicialize com SPR_init(), crie sprites com SPR_addSprite(..), mova/anime-os e chame SPR_update() uma vez por frame para enviar a lista de sprites ao VDP no V-Int. Esta é a versão atual do motor (usada quando LEGACY_SPRITE_ENGINE não está definido); a alocação de sprites de hardware do VDP é totalmente dinâmica a cada frame.

Tipos

SpriteVisibility

Enumeração dos estados de visibilidade de um sprite.

typedef enum
{
    VISIBLE,    // sprite visível (nenhum cálculo necessário)
    HIDDEN,     // sprite oculto (nenhum cálculo necessário)
    AUTO_FAST,  // visibilidade automática - RÁPIDA (cálculo global no meta-sprite)
    AUTO_SLOW,  // visibilidade automática - LENTA (cálculo por sprite de hardware)
} SpriteVisibility;

BoxCollision

Estrutura simples de caixa (box) para detecção de colisão.

typedef struct
{
    s8 x;   // posição X (borda esquerda)
    s8 y;   // posição Y (borda superior)
    u8 w;   // largura
    u8 h;   // altura
} BoxCollision;

CircleCollision

Estrutura simples de círculo, utilizável para detecção de colisão.

typedef struct
{
    s8 x;     // posição X do centro
    s8 y;     // posição Y do centro
    u16 ray;  // raio do círculo
} CircleCollision;

Collision

Definição de colisão com duas zonas: hit (dano recebido) e attack (dano causado, utilizável como hitbox alternativa). Cada zona é uma union entre box e círculo, selecionada pelos campos de tipo (COLLISION_TYPE_BOX ou COLLISION_TYPE_CIRCLE).

typedef struct _collision
{
    u8 typeHit;      // tipo da colisão de hit (COLLISION_TYPE_BOX ou COLLISION_TYPE_CIRCLE)
    u8 typeAttack;   // tipo da colisão de attack
    union {
        BoxCollision box;        // definição box se tipo = COLLISION_TYPE_BOX
        CircleCollision circle;  // definição círculo se tipo = COLLISION_TYPE_CIRCLE
    } hit;
    union {
        BoxCollision box;
        CircleCollision circle;
    } attack;
} Collision;

FrameVDPSprite

Informações de um único sprite de hardware (VDP) dentro de um frame de animação. Os offsets posicionam o sprite de hardware em relação à posição global do Sprite; as versões "Flip" são usadas quando o sprite está espelhado.

typedef struct
{
    u8 offsetY;      // offset Y relativo à posição global do Sprite
    u8 offsetYFlip;  // offset Y na versão espelhada (flip)
    u8 size;         // tamanho do sprite VDP (ver macro SPRITE_SIZE)
    u8 offsetX;      // offset X relativo à posição global do Sprite
    u8 offsetXFlip;  // offset X na versão espelhada (flip)
    u8 numTile;      // número de tiles deste sprite VDP (coerente com o campo size)
} FrameVDPSprite;

AnimationFrame

Frame de animação de um sprite: agrupa o tileset do frame e a lista de sprites de hardware (VDP) que o compõem.

typedef struct
{
    s8 numSprite;        // número de sprites VDP do frame; o bit 7 é flag interna do motor,
                         // use sempre (numSprite & 0x7F) para obter apenas a contagem
    u8 timer;            // tempo de exibição do frame (em 1/60 de segundo)
    TileSet* tileset;    // tileset com os tiles deste frame (ordenados para sprite)
    Collision* collision;// estrutura de colisão (não utilizada atualmente)
    FrameVDPSprite frameVDPSprites[]; // array de sprites VDP que compõem o frame
} AnimationFrame;

Animation

Estrutura de uma animação de sprite (sequência de frames).

typedef struct
{
    u8 numFrame;              // número de frames desta animação (máx. = 255)
    u8 loop;                  // índice do frame para onde o loop retorna (último índice se sem loop)
    AnimationFrame** frames;  // frames que compõem a animação
} Animation;

SpriteDefinition

Definição de sprite (recurso gerado normalmente pelo rescomp a partir de uma imagem): contém todas as animações e informações internas de alocação.

typedef struct
{
    u16 w;                   // largura da célula do frame em pixels
    u16 h;                   // altura da célula do frame em pixels
    Palette* palette;        // dados da palette padrão
    u16 numAnimation;        // número de animações deste sprite
    Animation** animations;  // definições das animações
    u16 maxNumTile;          // máx. de tiles usados por um único frame (p/ alocação de VRAM)
    u16 maxNumSprite;        // máx. de sprites VDP usados por um único frame (p/ alocação de sprites VDP)
} SpriteDefinition;

Sprite

Estrutura usada pelo motor para armazenar o estado de um sprite ativo em jogo. Atenção: sempre aloque objetos Sprite através de SPR_addSprite(..) (ou variantes), nunca manualmente.

typedef struct Sprite
{
    u16 status;            // estado interno e informações de alocação automática (interno)
    u16 visibility;        // visibilidade do frame atual para cada sprite VDP (máx. = 16)
    const SpriteDefinition* definition; // ponteiro para a definição do sprite
    void (*onFrameChange)(struct Sprite* sprite); // callback de troca de frame
    Animation* animation;  // cache do ponteiro da animação atual (interno)
    AnimationFrame* frame; // cache do ponteiro do frame atual (interno)
    s16 animInd;           // índice da animação atual (interno)
    s16 frameInd;          // índice do frame atual (interno)
    s16 timer;             // timer do frame atual (interno)
    s16 x;                 // posição X na tela com offset de 0x80 (posição interna do VDP)
    s16 y;                 // posição Y na tela com offset de 0x80 (posição interna do VDP)
    s16 depth;             // profundidade (Z) usada na ordenação de exibição
    u16 attribut;          // atributos do sprite + índice de tile em VRAM (ver TILE_ATTR_FULL())
    u32 data;              // campo livre para dados do usuário (flags, ponteiro...)
    struct Sprite* prev;   // sprite anterior na lista
    struct Sprite* next;   // próximo sprite na lista
} Sprite;

FrameChangeCallback

Tipo do callback de evento de troca de frame. O evento ocorre durante o processamento de troca de frame na chamada de SPR_update() (cuidado: o campo sprite->status não está atualizado nesse momento). Permite aplicar comportamento especial quando o frame acabou de mudar — por exemplo, interromper o loop de animação zerando sprite->timer ao chegar no último frame.

typedef void FrameChangeCallback(Sprite* sprite); // sprite: o sprite cujo frame acabou de mudar

Funções

void SPR_init(void)

Inicializa o motor de sprites com os parâmetros padrão (420 tiles reservados em VRAM). Também inicializa o sistema de alocação de sprites de hardware. Deve ser chamada antes de qualquer outra função SPR_*.

void SPR_initEx(u16 vramSize)

Inicializa o motor de sprites com parâmetros avançados. Aloca uma região de VRAM para os tiles de sprite e inicializa o sistema de alocação de sprites de hardware.

ParâmetroDescrição
vramSizeTamanho (em tiles) da região de VRAM para a alocação automática de tiles. Se 0, usa o tamanho padrão (420 tiles).

void SPR_end(void)

Encerra o motor de sprites e libera os recursos associados: a região de VRAM alocada e os sprites de hardware.

bool SPR_isInitialized(void)

Informa se o motor de sprites está inicializado.

Retorna: FALSE se o motor não está inicializado, TRUE caso contrário.

void SPR_reset(void)

Reinicializa o motor de sprites: libera todos os sprites alocados e seus recursos (VRAM e sprites de hardware), sem encerrar o motor.

Sprite* SPR_addSpriteEx(const SpriteDefinition* spriteDef, s16 x, s16 y, u16 attribut, u16 flag)

Adiciona um novo sprite com parâmetros específicos e o retorna. O sprite usa a configuração de flags fornecida para alocação automática de recursos e cálculo de visibilidade. Se a visibilidade automática não estiver habilitada, o sprite é considerado não visível por padrão (ver SPR_setVisibility(..)). Libere os recursos com SPR_releaseSprite(..) ou SPR_reset().

ParâmetroDescrição
spriteDefDados de SpriteDefinition a atribuir ao sprite.
xPosição X inicial.
yPosição Y inicial.
attributAtributos do sprite (ver macro TILE_ATTR()): palette, prioridade, flips e, em alocação manual, índice de tile em VRAM.
flagConfigurações do sprite: SPR_FLAG_DISABLE_DELAYED_FRAME_UPDATE (atualização de frame sempre imediata, pode gerar glitches), SPR_FLAG_AUTO_VISIBILITY (visibilidade automática), SPR_FLAG_FAST_AUTO_VISIBILITY (cálculo rápido, global no meta-sprite), SPR_FLAG_AUTO_VRAM_ALLOC (alocação automática de VRAM; sem ele, defina o índice de tile via attribut ou SPR_setVRAMTileIndex(..)), SPR_FLAG_AUTO_TILE_UPLOAD (upload automático dos tiles; sem ele, faça o upload manualmente), SPR_FLAG_INSERT_HEAD (insere no início da lista, equivalente a SPR_setDepth(SPR_MIN_DEPTH)). Recomenda-se SPR_FLAG_AUTO_VISIBILITY | SPR_FLAG_AUTO_VRAM_ALLOC | SPR_FLAG_AUTO_TILE_UPLOAD.

Retorna: o novo sprite, ou NULL se a operação falhou (mensagens podem ser geradas no console KMod).

Importante: com alocação automática de VRAM a criação pode falhar (retornar NULL) mesmo havendo VRAM suficiente, por causa da fragmentação. Use SPR_addSpriteExSafe(..) para tratar a fragmentação automaticamente.

Sprite* SPR_addSprite(const SpriteDefinition* spriteDef, s16 x, s16 y, u16 attribut)

Adiciona um novo sprite com alocação automática de recursos habilitada (VRAM e sprite de hardware) e visibilidade ligada. Os padrões podem ser alterados depois com SPR_setVRAMTileIndex(..), SPR_setAutoTileUpload(..) e SPR_setVisibility(..).

ParâmetroDescrição
spriteDefDados de SpriteDefinition a atribuir ao sprite.
xPosição X inicial.
yPosição Y inicial.
attributAtributos do sprite (ver macro TILE_ATTR()).

Retorna: o novo sprite, ou NULL se a operação falhou (mensagens podem ser geradas no console KMod).

A alocação pode falhar por fragmentação da VRAM mesmo com espaço livre suficiente; use SPR_addSpriteSafe(..) nesse caso.

Sprite* SPR_addSpriteExSafe(const SpriteDefinition* spriteDef, s16 x, s16 y, u16 attribut, u16 flag)

Versão "safe" de SPR_addSpriteEx(..): mesmos parâmetros e comportamento, mas em caso de falha de alocação de VRAM por fragmentação executa a desfragmentação e tenta novamente, garantindo sucesso sempre que houver espaço total suficiente.

ParâmetroDescrição
spriteDefDados de SpriteDefinition a atribuir ao sprite.
xPosição X inicial.
yPosição Y inicial.
attributAtributos do sprite (ver macro TILE_ATTR()).
flagConfigurações do sprite (mesmos flags de SPR_addSpriteEx(..)).

Retorna: o novo sprite, ou NULL se a operação falhou (mensagens podem ser geradas no console KMod).

Sprite* SPR_addSpriteSafe(const SpriteDefinition* spriteDef, s16 x, s16 y, u16 attribut)

Versão "safe" de SPR_addSprite(..): adiciona um sprite com alocação automática de recursos e visibilidade ligada, tratando a fragmentação da VRAM (desfragmenta e tenta de novo em caso de falha).

ParâmetroDescrição
spriteDefDados de SpriteDefinition a atribuir ao sprite.
xPosição X inicial.
yPosição Y inicial.
attributAtributos do sprite (ver macro TILE_ATTR()).

Retorna: o novo sprite, ou NULL se a operação falhou (mensagens podem ser geradas no console KMod).

void SPR_releaseSprite(Sprite* sprite)

Libera o sprite especificado: seus recursos (VRAM, sprites de hardware) são devolvidos ao motor e ele é removido da tela na próxima chamada de SPR_update().

ParâmetroDescrição
spriteSprite a liberar.

u16 SPR_getNumActiveSprite(void)

Informa quantos sprites estão ativos (adicionados com SPR_addSprite(..) ou SPR_addSpriteEx(..)).

Retorna: o número de sprites ativos.

u16 SPR_getUsedVDPSprite(void)

Informa o número (máximo) de sprites de hardware (VDP) usados pelos sprites ativos — soma do uso máximo de sprites de hardware de todos os sprites ativos. Útil para monitorar o limite de 80 sprites de hardware do VDP (64 em modo H32).

Retorna: o número máximo de sprites VDP utilizados pelos sprites ativos.

u16 SPR_getFreeVRAM(void)

Informa a quantidade de VRAM ainda livre (em tiles) na região reservada ao motor de sprites.

Retorna: a VRAM livre restante, em tiles.

u16 SPR_getLargestFreeVRAMBlock(void)

Informa o tamanho do maior bloco contíguo de VRAM livre (em tiles) do motor de sprites — valor relevante para diagnosticar falhas de alocação por fragmentação.

Retorna: o tamanho do maior bloco livre de VRAM, em tiles.

void SPR_enableVDPSpriteChecking(void)

Ativa a verificação de sprites de hardware: impede a adição de um novo sprite se possivelmente não houver sprites de hardware suficientes para exibi-lo (contando o uso máximo de sprites de hardware de todos os sprites ativos), garantindo assim que todos sejam sempre exibidos. Por padrão o motor permite adicionar sprites mesmo com risco de faltar sprites de hardware.

void SPR_disableVDPSpriteChecking(void)

Desativa a verificação de sprites de hardware (comportamento padrão): permite adicionar novos sprites mesmo com risco de esgotar os sprites de hardware, o que pode causar desaparecimento de sprites em algumas situações, mas permite gerenciar mais sprites ativos ao mesmo tempo.

void SPR_defragVRAM(void)

Desfragmenta a VRAM alocada para sprites. Útil quando a alocação de um sprite falha (SPR_addSprite(..) ou SPR_addSpriteEx(..) retornam NULL) mesmo havendo VRAM total suficiente.

u16** SPR_loadAllFramesEx(const SpriteDefinition* sprDef, u16 index, u16* totalNumTile, TransferMethod tm)

Carrega todos os frames de uma SpriteDefinition na VRAM a partir do índice de tile especificado, usando o método de transferência escolhido, e retorna a tabela de índices. A tabela é uma matriz 2D table[anim][frame] alocada dinamicamente — libere-a com MEM_free(..) quando não for mais necessária. Pode ser combinada com o callback de troca de frame (SPR_setFrameChangeCallback(..)) para atualizar automaticamente o índice de VRAM a cada frame com SPR_setVRAMTileIndex(..), evitando uploads de tiles em tempo de jogo (troca-se apenas o índice).

ParâmetroDescrição
sprDefSpriteDefinition cujos frames serão carregados na VRAM.
indexPosição de tile na VRAM onde os dados de tiles de todos os frames serão enviados.
totalNumTileSe não for NULL, recebe o número total de tiles usados para carregar todos os frames de animação.
tmMétodo de transferência: CPU, DMA, DMA_QUEUE ou DMA_QUEUE_COPY.

Retorna: a tabela 2D de índices, ou NULL se não houver memória suficiente para alocá-la.

Atenção: chame esta função em tempo de inicialização/carregamento, pois ela pode ser bem demorada (vários frames de vídeo).

u16** SPR_loadAllFrames(const SpriteDefinition* sprDef, u16 index, u16* totalNumTile)

Igual a SPR_loadAllFramesEx(..) usando DMA como método de transferência: carrega todos os frames da SpriteDefinition na VRAM no índice de tile especificado e retorna a tabela de índices 2D table[anim][frame] (libere com MEM_free(..)).

ParâmetroDescrição
sprDefSpriteDefinition cujos frames serão carregados na VRAM.
indexPosição de tile na VRAM onde os dados serão enviados.
totalNumTileSe não for NULL, recebe o número total de tiles usados.

Retorna: a tabela 2D de índices, ou NULL se não houver memória suficiente para alocá-la.

Atenção: chame em tempo de inicialização/carregamento, pois pode ser bem demorada (vários frames). Exemplo de uso com callback de troca de frame:

frameIndexes = SPR_loadAllFrames(sprite->definition, ind, NULL);
SPR_setFrameChangeCallback(sprite, &frameChanged);
...
void frameChanged(Sprite* sprite)
{
    u16 tileIndex = frameIndexes[sprite->animInd][sprite->frameInd];
    SPR_setVRAMTileIndex(sprite, tileIndex);
}

u16** SPR_loadAllIndexes(const SpriteDefinition* sprDef, u16 index, u16* totalNumTile)

Igual a SPR_loadAllFrames(..), porém apenas calcula a tabela de índices, sem carregar de fato os dados de tiles na VRAM (para isso use SPR_loadAllTiles(..) em seguida).

ParâmetroDescrição
sprDefSpriteDefinition para a qual calcular a tabela de índices.
indexPosição de tile na VRAM onde os dados serão futuramente enviados (nenhum upload é feito aqui).
totalNumTileSe não for NULL, recebe o número total de tiles necessários.

Retorna: a tabela 2D de índices, ou NULL se não houver memória suficiente para alocá-la.

u16 SPR_loadAllTiles(const SpriteDefinition* sprDef, u16 index, u16** indexes, const TransferMethod tm)

Igual a SPR_loadAllFrames(..), porém realiza apenas o upload dos dados de tiles do sprite para a VRAM; SPR_loadAllIndexes(..) deve ser chamada antes para construir a tabela de índices.

ParâmetroDescrição
sprDefSpriteDefinition cujos frames serão carregados na VRAM.
indexPosição de tile na VRAM onde os dados serão enviados.
indexesTabela 2D de índices com a posição de tile em VRAM de cada frame (construída previamente com SPR_loadAllIndexes(..)).
tmMétodo de transferência: CPU, DMA, DMA_QUEUE ou DMA_QUEUE_COPY.

Retorna: o número de tiles enviados à VRAM.

void SPR_setVisibility(Sprite* sprite, SpriteVisibility value)

Define o estado de visibility do sprite. O interesse em manter um sprite oculto é não consumir o orçamento de sprites por scanline: o VDP é limitado a no máximo 20 sprites ou 320 pixels de sprite por scanline (16 sprites/256 px em modo H32); ultrapassado o limite, os sprites seguintes não são renderizados. Quando um sprite fica não visível (automática ou manualmente), sua posição é levada para fora da tela verticalmente, deixando de consumir esse orçamento — por isso apenas o teste da coordenada X é necessário para determinar a visibilidade.

sprite_eng_legacy.h Motor de sprites legado (versão de setembro/2022)

Versão legada do motor de sprites do SGDK, correspondente ao estado de setembro de 2022, mantida apenas por compatibilidade com projetos antigos. Ela é compilada somente quando o símbolo LEGACY_SPRITE_ENGINE está definido (caso contrário, vale o sprite_eng.h atual). A API é quase idêntica à do motor atual; a principal diferença é o modelo de alocação de sprites de hardware do VDP: no motor legado cada Sprite reserva um bloco fixo de sprites VDP (com alocação automática via SPR_FLAG_AUTO_SPRITE_ALLOC ou manual via parâmetro spriteIndex/SPR_setSpriteTableIndex(..)), enquanto o motor novo faz essa alocação dinamicamente a cada frame. O header legado também não possui as funções mais recentes (SPR_getUsedVDPSprite, SPR_getFreeVRAM, SPR_getLargestFreeVRAMBlock, SPR_enableVDPSpriteChecking, SPR_disableVDPSpriteChecking, SPR_loadAllFramesEx, SPR_loadAllIndexes, SPR_loadAllTiles). Para projetos novos, prefira sempre o motor atual (sprite_eng.h).

Sprite

Estrutura de estado de um sprite ativo. Atenção: aloque sempre via SPR_addSprite(..). Em relação ao motor atual, contém campos extras ligados à alocação fixa de sprites VDP (VDPSpriteIndex, lastVDPSprite, lastNumSprite, spriteToHide).

typedef struct Sprite
{
    u16 status;            // estado interno e alocação automática (interno)
    u16 visibility;        // visibilidade do frame atual por sprite VDP (máx. = 16)
    const SpriteDefinition* definition; // definição do sprite
    void (*onFrameChange)(struct Sprite* sprite); // callback de troca de frame
    Animation* animation;  // cache da animação atual (interno)
    AnimationFrame* frame; // cache do frame atual (interno)
    s16 animInd;           // índice da animação atual (interno)
    s16 frameInd;          // índice do frame atual (interno)
    s16 timer;             // timer do frame atual (interno)
    s16 x;                 // posição X com offset de 0x80 (posição interna do VDP)
    s16 y;                 // posição Y com offset de 0x80 (posição interna do VDP)
    s16 depth;             // profundidade (Z) para ordenação
    u16 attribut;          // atributos + índice de tile em VRAM (ver TILE_ATTR_FULL())
    u16 VDPSpriteIndex;    // índice do primeiro sprite VDP alocado (0 se ainda não alocado);
                           // a quantidade alocada é definition->maxNumSprite
    VDPSprite* lastVDPSprite; // último sprite VDP usado (atualização de link, interno)
    u16 lastNumSprite;     // número de sprites VDP usados pelo frame atual (interno)
    s16 spriteToHide;      // interno
    u32 data;              // campo livre para dados do usuário
    struct Sprite* prev;   // sprite anterior na lista
    struct Sprite* next;   // próximo sprite na lista
} Sprite;

spriteSprite consultado.

Retorna: TRUE se o fim da animação atual foi alcançado, FALSE caso contrário.

bool SPR_setVRAMTileIndex(Sprite* sprite, s16 value)

Define a posição de tile em VRAM reservada ao sprite (alocação manual) ou retorna à alocação automática.

ParâmetroDescrição
spriteSprite alvo.
valuePosição de tile na VRAM para os dados do sprite. Use -1 para alocação automática.

Retorna: FALSE se a alocação automática falhou (só pode ocorrer com o sprite ativo), TRUE caso contrário.

bool SPR_setSpriteTableIndex(Sprite* sprite, s16 value)

Define o índice de sprite VDP a usar para este sprite. Por padrão o motor aloca os sprites VDP automaticamente, mas este método permite fixar manualmente o índice do primeiro sprite VDP. Ao definir o índice manualmente, garanta que existam sprites VDP contíguos disponíveis suficientes nessa posição para atender à necessidade do sprite. Função exclusiva do motor legado.

ParâmetroDescrição
spriteSprite alvo.
valueÍndice do primeiro sprite na tabela de sprites do VDP (> 0 e < 128). Use -1 para alocação automática.

Retorna: FALSE se a alocação automática falhou (só pode ocorrer com o sprite ativo), TRUE caso contrário.

Atenção: o sprite 0 não pode ser usado, pois é reservado internamente.

void SPR_setAutoTileUpload(Sprite* sprite, bool value)

Ativa/desativa o upload automático dos dados de tiles do sprite para a VRAM.

ParâmetroDescrição
spriteSprite alvo.
valueTRUE para ativar o upload automático; FALSE para desativá-lo (você passa a ser responsável pelo upload).

void SPR_setDelayedFrameUpdate(Sprite* sprite, bool value)

Ativa/desativa o adiamento da atualização de frame quando o DMA fica sem capacidade de transferência.

ParâmetroDescrição
spriteSprite alvo.

SpriteVisibility SPR_getVisibility(Sprite* sprite)

Retorna o estado de visibility configurado (VISIBLE, HIDDEN, AUTO_FAST ou AUTO_SLOW). Atenção: diferente de SPR_isVisible(..), que retorna a visibilidade efetiva.

ParâmetroDescrição
spriteSprite consultado.

Retorna: o estado de visibility do sprite.

bool SPR_isVisible(Sprite* sprite, bool recompute)

Retorna o estado visível efetivo do sprite (significativo apenas com visibilidade AUTO). Apenas a posição X é usada para determinar a visibilidade.

ParâmetroDescrição
spriteSprite consultado.
recomputeForça o recálculo da visibilidade; só é necessário se SPR_update() não foi chamado desde a última mudança de posição (pode forçar o processamento de atualização de frame).

Retorna: TRUE se o sprite está visível, FALSE caso contrário.

void SPR_setVisibility(Sprite* sprite, SpriteVisibility value)

Define o estado de visibility do sprite. Ocultar um sprite evita que ele consuma o orçamento de sprites por scanline do VDP (máx. 20 sprites ou 320 px por scanline; 16 sprites/256 px em H32) — quando não visível, sua posição é levada para fora da tela verticalmente, e só o teste da coordenada X é usado na determinação.

ParâmetroDescrição
spriteSprite alvo.
valueVISIBLE, HIDDEN, AUTO_FAST (automática global, só posição X) ou AUTO_SLOW (automática por sprite de hardware, só posição X).

SPR_setAlwaysVisible(sprite, value) (macro, obsoleta)

Macro obsoleta (deprecated). Seu uso gera erro de compilação via _Pragma("GCC error ...").

Use SPR_setVisibility(..) em seu lugar.

SPR_setNeverVisible(sprite, value) (macro, obsoleta)

Macro obsoleta (deprecated). Seu uso gera erro de compilação via _Pragma("GCC error ...").

Use SPR_setVisibility(..) em seu lugar.

SPR_computeVisibility(sprite) (macro, obsoleta)

Macro obsoleta (deprecated). Seu uso gera erro de compilação via _Pragma("GCC error ...").

Use SPR_isVisible(sprite, TRUE) em seu lugar.

void SPR_clear(void)

Limpa todos os sprites exibidos, sem liberar seus recursos; eles voltam a ser exibidos ao chamar SPR_update().

void SPR_update(void)

Atualiza e exibe a lista de sprites ativos: atualiza os estados internos e prepara o cache da lista de sprites para envio ao hardware (VDP) no V-Int.
