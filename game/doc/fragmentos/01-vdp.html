vdp.h Núcleo do VDP — inicialização, registradores, resolução e recursos de vídeo

Este módulo fornece os métodos gerais de controle do VDP (Video Display Processor), o chip de vídeo do Mega Drive/Genesis: inicialização do subsistema, leitura e escrita de registradores, configuração de resolução, modos de scroll e interlace, posicionamento do plano Window, controle de interrupções (VInt, HInt, Ext) e utilitários de sincronização (esperar VBlank/VSync, FIFO, DMA). Também define os endereços dos ports do VDP, as flags do registrador de status, os comandos de acesso a VRAM/CRAM/VSRAM e a organização padrão de tiles na VRAM usada pelo SGDK.

Aviso importante: o SGDK espera que a VRAM esteja organizada com os dados de tile localizados antes dos tilemaps e tabelas: 0000-XXXX = dados de tile; XXXX-FFFF = tilemaps e tabelas (tabela de scroll horizontal, tabela de sprites, planos B/A e plano Window). Se essa organização não for respeitada, várias facilidades do SGDK podem falhar.

Tipos

VDPPlane

Enumeração usada por diversos métodos para indicar sobre qual plane a operação deve atuar: plano de fundo A, plano de fundo B ou plano Window.

typedef enum
{
    BG_A = 0,    // plano de fundo A
    BG_B = 1,    // plano de fundo B
    WINDOW = 2   // plano Window (sem scroll, sobrepõe o plano A)
} VDPPlane;

Funções

#define VDP_READ_VRAM_ADDR(adr)

Monta o comando de 32 bits do VDP para ler a partir do endereço de VRAM especificado. O valor resultante deve ser escrito no port de controle antes de ler o port de dados.

ParâmetroDescrição
adrEndereço em VRAM (0 a 0xFFFF).

Retorna: comando de 32 bits pronto para ser escrito no port de controle do VDP.

#define VDP_READ_CRAM_ADDR(adr)

Monta o comando do VDP para ler a partir do endereço de CRAM (memória de cores) especificado.

ParâmetroDescrição
adrEndereço em CRAM (0 a 0x7F — 64 entradas de cor de 2 bytes).

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_READ_VSRAM_ADDR(adr)

Monta o comando do VDP para ler a partir do endereço de VSRAM (memória de scroll vertical) especificado.

ParâmetroDescrição
adrEndereço em VSRAM (0 a 0x7F).

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_WRITE_VRAM_ADDR(adr)

Monta o comando do VDP para escrever no endereço de VRAM especificado. Após escrever o comando no port de controle, os dados escritos no port de dados vão para a VRAM (com auto-incremento configurado por VDP_setAutoInc()).

ParâmetroDescrição
adrEndereço em VRAM (0 a 0xFFFF).

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_WRITE_CRAM_ADDR(adr)

Monta o comando do VDP para escrever no endereço de CRAM especificado (atualização de cores das palettes).

ParâmetroDescrição
adrEndereço em CRAM (0 a 0x7F).

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_WRITE_VSRAM_ADDR(adr)

Monta o comando do VDP para escrever no endereço de VSRAM especificado (valores de scroll vertical).

ParâmetroDescrição
adrEndereço em VSRAM (0 a 0x7F).

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_DMA_VRAM_ADDR(adr)

Monta o comando do VDP para disparar uma transferência DMA com destino no endereço de VRAM especificado.

ParâmetroDescrição
adrEndereço de destino em VRAM.

Retorna: comando de 32 bits para o port de controle do VDP (com bit de DMA ativado).

Os registradores de origem, tamanho e modo do DMA devem estar configurados antes de escrever este comando. Em geral, prefira a API de mais alto nível do módulo DMA do SGDK.

#define VDP_DMA_CRAM_ADDR(adr)

Monta o comando do VDP para disparar uma transferência DMA com destino no endereço de CRAM especificado.

ParâmetroDescrição
adrEndereço de destino em CRAM.

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_DMA_VSRAM_ADDR(adr)

Monta o comando do VDP para disparar uma transferência DMA com destino no endereço de VSRAM especificado.

ParâmetroDescrição
adrEndereço de destino em VSRAM.

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_DMA_VRAMCOPY_ADDR(adr)

Monta o comando do VDP para disparar uma cópia DMA de VRAM para VRAM (operação VRAM copy) com destino no endereço especificado.

ParâmetroDescrição
adrEndereço de destino em VRAM.

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_VERT_SCROLL(adr)

Atalho para escrever na tabela de scroll vertical — equivalente a VDP_WRITE_VSRAM_ADDR(adr).

ParâmetroDescrição
adrDeslocamento dentro da VSRAM.

Retorna: comando de 32 bits para o port de controle do VDP.

#define VDP_HORZ_SCROLL(adr)

Atalho para escrever na tabela de scroll horizontal em VRAM — equivalente a VDP_WRITE_VRAM_ADDR(VDP_HSCROLL_TABLE + adr).

ParâmetroDescrição
adrDeslocamento dentro da tabela de scroll horizontal.

Retorna: comando de 32 bits para o port de controle do VDP.

No header o texto original menciona VDP_SCROLL_H; a implementação usa o endereço atual da tabela de scroll horizontal (hscrl_addr).

#define GET_VDP_STATUS(flag)

Testa o registrador de status do VDP contra a flag especificada (ver constantes VDP_XXX_FLAG). Lê diretamente o port de controle.

ParâmetroDescrição
flagFlag (ou combinação de flags) a testar, ex.: VDP_VBLANK_FLAG.

Retorna: valor diferente de zero se a(s) flag(s) estiver(em) ativa(s).

#define IS_PAL_SYSTEM

Testa se o sistema atual é PAL (50 Hz), consultando a flag VDP_PALMODE_FLAG do registrador de status.

Retorna: valor diferente de zero em sistema PAL; zero em sistema NTSC (60 Hz).

#define GET_HVCOUNTER

Lê o contador HV do VDP (port VDP_HVCOUNTER_PORT): o byte alto contém o contador vertical e o byte baixo o contador horizontal.

Retorna: valor de 16 bits do contador HV.

#define GET_HCOUNTER

Extrai apenas o contador horizontal do contador HV.

Retorna: contador horizontal (byte baixo do HV counter).

#define GET_VCOUNTER

Extrai apenas o contador vertical do contador HV.

Retorna: contador vertical (byte alto do HV counter).

O V-Counter bruto "retrocede" (rollback) durante o VBlank; para uma leitura linearizada use VDP_getAdjustedVCounter().

void VDP_init(void)

Inicializa todo o subsistema do VDP: restaura os registradores do VDP aos valores padrão, reinicializa os sprites e chama VDP_resetScreen() para reinicializar os planos de fundo e as palettes.

void VDP_resetScreen(void)

Reinicializa os planos de fundo e as palettes: limpa a VRAM (apaga os planes e recarrega a fonte), zera os scrolls e restaura as palettes padrão (rampas de cinza, vermelho, verde e azul).

u8 VDP_getReg(u16 reg)

Obtém o valor de um registrador do VDP. Como os registradores do VDP não podem ser lidos pelo hardware, o SGDK mantém uma cópia (cache) em RAM dos valores escritos.

ParâmetroDescrição
regNúmero do registrador cujo valor se deseja obter.

Retorna: valor do registrador especificado (segundo o cache do SGDK).

void VDP_setReg(u16 reg, u8 value)

Escreve um valor em um registrador do VDP.

ParâmetroDescrição
regNúmero do registrador. Ativar o bit 7 do número (reg | 0x80) faz a escrita ir direto ao VDP sem atualizar o cache do SGDK, de modo que VDP_getReg(reg) continuará retornando o valor anterior.
valueValor a escrever.

bool VDP_getEnable(void)

Retorna o estado de habilitação do display do VDP.

Retorna: TRUE se o display está habilitado.

bool VDP_isEnable(void)

Retorna o estado de habilitação do display do VDP (idêntico a VDP_getEnable(), apenas outro nome).

Retorna: TRUE se o display está habilitado.

void VDP_setEnable(bool value)

Habilita ou desabilita o display do VDP. Desabilitar temporariamente o display acelera as transferências para a memória de vídeo, pois o VDP deixa de disputar o acesso à VRAM com a renderização.

ParâmetroDescrição
valueTRUE para habilitar o display, FALSE para desabilitar (tela exibe apenas a cor de fundo).

u16 VDP_getScanlineNumber(void)

Retorna o número total de scanlines do sistema.

Retorna: 312 em sistema PAL e 262 em sistema NTSC.

u16 VDP_getScreenHeight(void)

Retorna a resolução vertical atual da tela.

Retorna: sempre 224 em NTSC (único modo suportado); em PAL pode retornar 240 se o modo de 240 linhas estiver ativo.

void VDP_setScreenHeight224(void)

Define a resolução vertical em 224 pixels (28 tiles). É o único modo aceito em sistemas NTSC.

void VDP_setScreenHeight240(void)

Define a resolução vertical em 240 pixels (30 tiles).

Funciona apenas em sistemas PAL.

u16 VDP_getScreenWidth(void)

Retorna a resolução horizontal atual da tela.

Retorna: 320 (modo H40) ou 256 (modo H32), conforme o modo horizontal ativo.

void VDP_setScreenWidth256(void)

Define a resolução horizontal em 256 pixels (modo H32, 32 tiles de largura visível).

void VDP_setScreenWidth320(void)

Define a resolução horizontal em 320 pixels (modo H40, 40 tiles de largura visível — modo padrão).

u16 VDP_getPlaneWidth(void)

Retorna a largura atual dos planes de fundo, em tiles.

Retorna: 32, 64 ou 128.

u16 VDP_getPlaneHeight(void)

Retorna a altura atual dos planes de fundo, em tiles.

Retorna: 32, 64 ou 128.

void VDP_setPlaneSize(u16 w, u16 h, bool setupVram)

Define o tamanho dos planes de fundo (em tiles). Planes maiores consomem mais VRAM para os tilemaps.

ParâmetroDescrição
wLargura em tiles. Valores possíveis: 32, 64 ou 128.
hAltura em tiles. Valores possíveis: 32, 64 ou 128.
setupVramSe TRUE, os tilemaps e tabelas são automaticamente remapeados na VRAM conforme o novo tamanho de plane. Na dúvida, mantenha TRUE.

Atenção: garanta que a VRAM esteja organizada de forma que os tilemaps tenham espaço suficiente. Após a remapeação será preciso redesenhar os backgrounds, e o motor de sprites pode precisar realocar sua região de VRAM se a localização mudou. Nem toda combinação é válida no hardware (o VDP limita a área total do tilemap; por exemplo, 128x128 não é suportado).

u8 VDP_getHorizontalScrollingMode(void)

Retorna o modo de scroll horizontal dos planes.

Retorna: HSCROLL_PLANE, HSCROLL_TILE ou HSCROLL_LINE.

u8 VDP_getVerticalScrollingMode(void)

Retorna o modo de scroll vertical dos planes.

Retorna: VSCROLL_PLANE ou VSCROLL_COLUMN.

void VDP_setScrollingMode(u16 hscroll, u16 vscroll)

Define os modos de scroll dos planes de fundo.

ParâmetroDescrição
hscrollModo de scroll horizontal: HSCROLL_PLANE = deslocamento aplicado ao plane inteiro; HSCROLL_TILE = deslocamento com granularidade de tile (blocos de 8 pixels); HSCROLL_LINE = deslocamento por linha (1 pixel).
vscrollModo de scroll vertical: VSCROLL_PLANE = deslocamento aplicado ao plane inteiro; VSCROLL_COLUMN = deslocamento com granularidade de coluna de 2 tiles (blocos de 16 pixels).

Use VDP_setHorizontalScroll(), VDP_setHorizontalScrollTile(), VDP_setHorizontalScrollLine(), VDP_setVerticalScroll() e VDP_setVerticalScrollTile() (em vdp_bg.h) para definir os deslocamentos de acordo com o modo ativo.

Retorna o estado do travamento (latching) do contador HV na interrupção externa INT2 (recurso usado por light guns).

Retorna: valor diferente de zero se o latching está ativo.

Ativa ou desativa o travamento do contador HV na INT2. Com o latching ativo, o HV Counter congela seu valor no momento da interrupção externa, permitindo posicionamento preciso de light gun.

void VDP_setVInterrupt(bool value)

Habilita ou desabilita a interrupção vertical (VInt).

ParâmetroDescrição

void VDP_setHInterrupt(bool value)

ParâmetroDescrição
valueTRUE para habilitar, FALSE para desabilitar.

void VDP_setExtInterrupt(bool value)

Habilita ou desabilita a interrupção externa (INT2, gerada pelo pino TH dos controles — usada por light guns em conjunto com o HV latching).

ParâmetroDescrição
valueTRUE para habilitar, FALSE para desabilitar.

void VDP_setHilightShadow(bool value)

Habilita ou desabilita o efeito Hilight/Shadow (modo shadow/highlight do VDP), que permite escurecer ou clarear pixels conforme a prioridade dos tiles e sprites, simulando mais tons na tela.

ParâmetroDescrição

void VDP_setScanMode(u16 mode)

Define o modo de varredura (scan) do display. A mudança entra em vigor no próximo período de blanking. No modo interlaçado 1, o mesmo padrão é exibido nas linhas adjacentes dos campos pares e ímpares; no modo interlaçado 2, padrões diferentes podem ser exibidos (dobrando a resolução vertical efetiva). O número de células na tela permanece o mesmo em qualquer modo.

ParâmetroDescrição
modeValores aceitos: INTERLACED_NONE, INTERLACED_MODE1, INTERLACED_MODE2.

vdp_bg.h Planos de fundo — scroll, texto, bitmaps e imagens

Este módulo fornece as facilidades de manipulação dos planos de fundo A e B (e do plano Window) do VDP do Mega Drive: definição de scroll horizontal e vertical em todos os modos suportados pelo hardware (plane, tile, linha e coluna de 2 tiles), limpeza de planes, desenho de texto com a fonte do sistema, desenho de números e carga/exibição de bitmaps e de estruturas Image (tileset + tilemap + palette) geradas pelo rescomp. Use-o sempre que precisar desenhar conteúdo estático ou textual em um plane, ou animar o scroll dos backgrounds.

Constantes e macros

NomeValorDescrição
curTileIndextern u16Variável global que contém a posição (índice) atual de tile na VRAM onde os próximos dados de tile serão carregados por VDP_drawBitmap() / VDP_drawImage().

Tipos

Image

Estrutura que reúne todos os dados necessários para definir uma imagem em um plano de fundo: palette, tileset e tilemap. É o formato produzido pelo rescomp para recursos do tipo IMAGE. Use o método unpackImage() para descompactar quando a compressão estiver habilitada nas estruturas TileSet ou TileMap.

typedef struct
{
    Palette *palette;   // dados da palette da imagem
    TileSet *tileset;   // definição dos tiles da imagem
    TileMap *tilemap;   // definição do tilemap da imagem
} Image;

Define o scroll horizontal do plane no modo plain (plano inteiro). O VDP suporta 3 modos de scroll horizontal: plain (plane inteiro), tile (blocos de 8 pixels) e line (por pixel/linha); use VDP_setScrollingMode() para trocar o modo.
